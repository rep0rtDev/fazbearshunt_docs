# Описание

Команды использующиеся в Fazbear's Hunt. Стоит использовать вместе с [Player:Team](https://wiki.facepunch.com/gmod/Player:Team)

## Значения <span class="fh-badge shared">shared</span>

| `TEAM_SURVIVOR` | `2700` | Команда выживших |
| `TEAM_PILLS` | `2701` | Команда аниматроников по умолчанию |
| `TEAM_ADMIN` | `2702` | Команда для администрации сервера, **не используется** |
| `TEAM_EDITOR` | `2703` | Команда для использования FH Editor |
| `TEAM_SPECTATOR` | `1002` | Команда для мёртвых игроков |

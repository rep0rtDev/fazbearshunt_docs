> <span class="fh-badge client">client</span> **DisplayText(@string@ topText = "", @string@ bottomText = "", @number@ duration)**

# Описание

Позволяет показать игроку некую информацию на экране. Эта функция используется после Слепой Ярости, оповещая жертву способности. 

Также раньше использовалась для отображения подобранного подарка до версии `5.0.0`.

# Аргументы

> `1` @string@ **topText** = ""

- Верхний текст.

> `2` @string@ **bottomText** = ""

- Нижний текст, чуть меньше верхнего.

> `3` @number@ **duration**

- Продолжительность показа.

> <span class="fh-badge server">server</span> @Player@ **TaseAnimatronic(@Player@ ply, @Player@ taserer)**

# Описание

Если игрок - аниматроник, бьёт его током (так, как это делает Шокер).

# Аргументы

> `1` @Player@ **ply**

- Игрок которого надо ударить током.

> `2` @Player@ **taserer**

- Игрок, который вызывает ивент удара током.

# Возвращает

> `1` @Player@

- Возвращает игрока, если найден. В противном случае выдаст nil.

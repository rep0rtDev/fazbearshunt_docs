> <span class="fh-badge server">server</span> @boolean@ **FH_AnimatronicJumpscare(@Player@ ply, @Entity@ ent, @Player@ target, @table@ data)**

# Описание

Вызывается в начале успешного скримера.

# Аргументы

> `1` @Player@ **ply**

- Игрок который пытается заскримерить.

> `2` @Entity@ **ent**

- Пилл-Энтити игрока `ply`.

> `3` @Player@ **target**

- Игрок которого пытаются заскримерить.

> `4` @table@ **data**

- Данные о текущем скримере.

### Содержание таблицы data

| Ключ | Тип | Значение |
|---|---|---|
| delay | @number@ | Продолжительность скримера |
| char | @string@ | Имя аниматроника, использующееся для проигрывания войслайнов |
| dist | @number@ | Дистанция между жертвой и нападющим |
| wep | @string@ | Класс оружия в руках нападющего |

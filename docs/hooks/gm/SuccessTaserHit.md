> <span class="fh-badge server">server</span> **SuccessTaserHit(@Player@ ply, @Entity@ ent, @Player@ taserer)**

# Описание

Вызывается после успешного попадания Шокером по `ply`.

# Аргументы

> `1` @Player@ **ply**

- Игрок которого ударили током.

> `2` @Entity@ **ent**

- Пилл-Энтити игрока `ply`.

> `3` @Player@ **taserer**

- Игрок который сделал выстрел из Шокера.

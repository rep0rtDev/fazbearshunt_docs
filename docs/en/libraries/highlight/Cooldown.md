> <span class="fh-badge server">server</span> **highlight.Cooldown(@Player@ ply, @number@ duration)**

# Description

Sets a cooldown on highlighting. The cooldown is automatically taken into account only in [highlight.ByDistance](/en/libraries/highlight/ByDistance)

# Arguments

> `1` @Player@ **ply**

- The player the cooldown is set for.

> `2` @number@ **duration**

- The duration of the highlight cooldown.

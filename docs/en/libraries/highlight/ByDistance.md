> <span class="fh-badge server">server</span> **highlight.ByDistance(@Player@ ply, @Entity@ pill)**

# Description

Highlights all survivors for the player `ply`. All of the gamemode's animatronics with the "highlight" ability use this exact function.

# Arguments

> `1` @Player@ **ply**

- The player who triggers the highlight.

> `2` @Entity@ **pill**

- The player's Pill entity.

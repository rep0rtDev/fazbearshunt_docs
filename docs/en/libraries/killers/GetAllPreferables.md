> <span class="fh-badge shared">shared</span> @table@ **killers.GetAllPreferables(@boolean@ secondaries = false)**

# Description

Returns a table of all playable Pills. (Those that can appear in the animatronic selection.)

Setting `secondaries` to `true` includes secondary animatronics in the list, such as Shadow Freddy or Toy Chica.

# Returns

> `1` @table@

- A table of playable Pills.

> <span class="fh-badge shared">shared</span> @string@ **killers.GetName(@string@ pill)**

# Description

Returns a Pill's technical name.

# Arguments

> `1` @string@ **pill**

- The Pill's name, for example `pill_wfreddy2`.

# Returns

> `1` @string@

- The Pill's technical name.

## Example

```lua
print( killers.GetName( "pill_wfreddy2" ) )
```

**Output**:

```lua
freddy
```

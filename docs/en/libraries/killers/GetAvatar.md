> <span class="fh-badge shared">shared</span> @IMaterial@ or @nil@ **killers.GetAvatar(@string@ pill)**

# Description

Lets you get a Pill's avatar, which is used, for example, in the player list and in the animatronic selection.

# Arguments

> `1` @string@ **pill**

- The Pill's name, for example `pill_wfreddy2`.

# Returns

> `1` @IMaterial@ or @nil@

- The avatar of the given Pill, or `nil` if not found.

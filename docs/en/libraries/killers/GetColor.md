> <span class="fh-badge shared">shared</span> @Color@ **killers.GetColor(@string@ pill)**

# Description

Lets you get a Pill's color.

# Arguments

> `1` @string@ **pill**

- The Pill's name, for example `pill_wfreddy2`.

# Returns

> `1` @Color@ = Color(255,255,255)

- The color of the Pill. If not found, returns white color.

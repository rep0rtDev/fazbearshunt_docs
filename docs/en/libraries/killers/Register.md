> <span class="fh-badge shared">shared</span> **killers.Register(@string@ pill, @string@ name, @string@ fullname, @Color@ color, @string@ category)**

# Description

Lets you get a Pill's portrait, which is used in the animatronic interface, in the bottom left.

# Arguments

> `1` @string@ **pill**

- The Pill's name, for example `pill_wfreddy2`.

> `2` @string@ **name**

- The Pill's technical name, for example `freddy`.

> `3` @string@ **name**

- The Pill's full name. A translatable string can be used.

> `4` @Color@ **color**

- The animatronic interface color.

> `5` @string@ **category**

- The Pill's category. Currently it is only used in the Admin Panel.

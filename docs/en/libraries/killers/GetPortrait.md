> <span class="fh-badge shared">shared</span> @IMaterial@ or @nil@ **killers.GetPortrait(@string@ pill)**

# Description

Lets you get a Pill's portrait, which is used in the animatronic interface, in the bottom left.

# Arguments

> `1` @string@ **pill**

- The Pill's name, for example `pill_wfreddy2`.

# Returns

> `1` @IMaterial@ or @nil@

- The portrait of the given Pill, or `nil` if not found.

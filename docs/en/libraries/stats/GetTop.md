> <span class="fh-badge server">server</span> @Player@, @number@ **stats.GetTop(@string@ statName)**

# Description

Returns the player with the best given statistic.

# Arguments

> `1` @string@ **statName**

- The statistic's name.

# Returns

> `1` @Player@ **ply**

- The player with the best value for the statistic.

> `2` @number@ **value**

- The statistic's value.

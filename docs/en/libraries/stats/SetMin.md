> <span class="fh-badge server">server</span> **stats.SetMin(@string@ name, @number@ minValue)**

# Description

Sets the minimum "interest" value. If a player hasn't reached this level in the statistic, it won't be shown.

# Arguments

> `1` @string@ **name**

- The statistic's name.

> `2` @number@ **minValue**

- The minimum interest value..

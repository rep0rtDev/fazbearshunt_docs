> <span class="fh-badge client">client</span> **playerlist.AddIconSet(@string@ icon, @string@ material, @number@ size = 16, @Color@ color = Color(255,255,255))**

# Description

Adds an icon set that can later be assigned to specific players.

# Arguments

> `1` @string@ **icon**

- The icon's name.

> `2` @string@ **material**

- The path to the icon's texture.

> `3` @string@ **size** = 16

- The icon's size.

> `4` @string@ **color** = Color(255,255,255)

- The color of the player's nickname.

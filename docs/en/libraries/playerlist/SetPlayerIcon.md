> <span class="fh-badge client">client</span> **playerlist.SetPlayerIcon(@string@ steamID64, @string@ icon)**

# Description

Sets an icon for a player in the player list.

Before that, read how to add icon sets - [playerlist.AddIconSet()](/en/libraries/playerlist/AddIconSet)

# Arguments

> `1` @string@ **steamID64**

- The [Player:SteamID64](https://wiki.facepunch.com/gmod/Player:SteamID64) of the player the icon is being set for.

> `2` @string@ **icon**

- The icon's name.

> <span class="fh-badge client">client</span> @string@ **playerlist.GetPlayerIcon(@string@ steamID64)**

# Description

Lets you find out a player's current icon in the player list via their [Player:SteamID64](https://wiki.facepunch.com/gmod/Player:SteamID64)

To set an icon, see [playerlist.SetPlayerIcon()](/libraries/playerlist/SetPlayerIcon)

# Arguments

> `1` @string@ **steamID64**

- The [Player:SteamID64](https://wiki.facepunch.com/gmod/Player:SteamID64) of the player the icon is being set for.

# Returns

> `1` @string@

- The icon's name.

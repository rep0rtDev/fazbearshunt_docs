> <span class="fh-badge shared">shared</span> @boolean@ **PlayerInOutworld(@Player@ ply)**

# Description

Returns whether the player is in Golden Freddy's dimension.

::: warning Keep in mind
On the client it (as a rule) always returns `false`.
:::

# Arguments

> `1` @Player@ **ply**

- The player being checked.

# Returns

> `1` @boolean@

- Is the player in G.F.'s dimension?

> <span class="fh-badge client">client</span> **DisplayText(@string@ topText = "", @string@ bottomText = "", @number@ duration)**

# Description

Lets you show the player some information on screen. This function is used after Blind Rage to notify the ability's victim.

It was also used to display a picked-up gift before version `5.0.0`.

# Arguments

> `1` @string@ **topText** = ""

- The top text.

> `2` @string@ **bottomText** = ""

- The bottom text, slightly smaller than the top one.

> `3` @number@ **duration**

- How long the text is shown.

> <span class="fh-badge server">server</span> @Player@ **TaseAnimatronic(@Player@ ply, @Player@ taserer)**

# Description

If the player is an animatronic, shocks them with electricity (the way the Taser does).

# Arguments

> `1` @Player@ **ply**

- The player to be shocked.

> `2` @Player@ **taserer**

- The player who triggers the shock event.

# Returns

> `1` @Player@

- Returns the player if one is found. Otherwise returns nil.

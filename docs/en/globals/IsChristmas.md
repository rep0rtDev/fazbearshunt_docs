> <span class="fh-badge shared">shared</span> @boolean@ **IsChristmas()**

# Description

Lets you find out whether it is currently the Christmas season — December or January.

::: warning Keep in mind
The client and the server may return different values because of their different time zones.
:::

# Returns

> `1` @boolean@

- `true` if it is currently the Christmas season, `false` if not.

> <span class="fh-badge shared">shared</span> @boolean@ @Entity@:IsInvisible()

# Description

Is the player invisible?

:::tip Note
For this to return `true`, the entity must have the `models/null` material or be `:GetNoDraw() == true`.
:::

# Returns

> `1` @boolean@

- Returns true if the player is invisible, and false if not.

> <span class="fh-badge shared">shared</span> @Player@:SetOnlyAudibleByTeammates(@boolean@ onlyAudibleByTeammates)

# Description

Sets the audibility status so that the player can be heard only by their teammates. Used for Bonnie when he uses "Yours is Mine".

:::warning Warning
Does nothing on the client.
:::

# Arguments

> `1` @boolean@ **onlyAudibleByTeammates**

- Whether the player should be heard only by their teammates.

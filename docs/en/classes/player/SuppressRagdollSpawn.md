> <span class="fh-badge server">server</span> @Player@:SuppressRagdollSpawn(@boolean@ suppress)

# Description

Allows you to cancel the spawn of the death ragdoll. After a single spawn attempt it is automatically reset to `false`.

# Arguments

> `1` @boolean@ **suppress**

- To prevent a death ragdoll from spawning, pass true; to allow it, pass false.

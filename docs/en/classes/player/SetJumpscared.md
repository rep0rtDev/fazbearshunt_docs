> <span class="fh-badge shared">shared</span> @Player@:SetJumpscared(@boolean@ isJumpscared)

# Description

Sets whether the player is being jumpscared.

:::tip Note
This function is already used automatically inside `performJumpscare`.
:::

:::warning Warning
Although this is a <span class="fh-badge shared">shared</span> function and you can use it on the client, you most likely don't need to.
:::

# Arguments

> `1` @boolean@ **isJumpscared**

- Pass true if the player is being jumpscared, and false if not.

# Description

Teams used in Fazbear's Hunt. Should be used together with [Player:Team](https://wiki.facepunch.com/gmod/Player:Team)

## Values <span class="fh-badge shared">shared</span>

| Variable | Number | Description |
|---|---|---|
| `TEAM_SURVIVOR` | `2700` | The survivors' team |
| `TEAM_PILLS` | `2701` | The default animatronics' team |
| `TEAM_ADMIN` | `2702` | Team for server administration, **not used** |
| `TEAM_EDITOR` | `2703` | Team for using the FH Editor |
| `TEAM_SPECTATOR` | `1002` | Team for dead players |

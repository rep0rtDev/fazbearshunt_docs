> <span class="fh-badge shared">shared</span> @Player@:SetJumpscared(@boolean@ isJumpscared)

# Описание

Устанавливает статус того, скримерят ли игрока.

:::tip На заметку
Эта функция уже автоматически используется внутри `performJumpscare`.
:::

:::warning Внимнаие
Хоть это и <span class="fh-badge shared">shared</span> функция, вы можете использовать её на клиенте, хотя скорее всего не обязаны.
:::

# Аргументы

> `1` @boolean@ **isJumpscared**

- Введите true, если игрока скримерят, а если нет - false.

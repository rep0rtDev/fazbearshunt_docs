> <span class="fh-badge server">server</span> @Player@:ForceListenPlayer(@Player@ listenPlayer)

# Описание

Принудительно заставляет игрока слышать только указанного игрока (всех остальных - выключить).

# Аргументы

> `1` @Player@ **listenPlayer**

- Чтобы посмертного регдолла не было, введите true, а чтобы можно было - false.

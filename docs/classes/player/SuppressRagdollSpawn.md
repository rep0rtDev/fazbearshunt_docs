> <span class="fh-badge server">server</span> @Player@:SupressRagdollSpawn(@boolean@ suppress)

# Описание

Позволяет отменить спавн посмертного регдолла. После одной попытки спавна автоматически сбрасывается в `false`.

# Аргументы

> `1` @boolean@ **suppress**

- Чтобы посмертного регдолла не было, введите true, а чтобы можно было - false.

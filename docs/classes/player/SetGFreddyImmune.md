> <span class="fh-badge shared">shared</span> @Player@:SetGFreddyImmune(@boolean@ isImmune)

# Описание

Иммунитет к способности Золотого Фредди (Загранное Измерение).

# Аргументы

> `1` @boolean@ **isImmune**

- Введите `true`, чтобы Золотой Фредди не смог забрать игрока в своё измерение, а чтобы смог - `false`.

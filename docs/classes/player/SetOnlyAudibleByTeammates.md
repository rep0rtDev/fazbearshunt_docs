> <span class="fh-badge shared">shared</span> @Player@:SetOnlyAudibleByTeammates(@boolean@ onlyAudibleByTeammates)

# Описание

Установка статуса слышимости игрока, при котором его будут слышать только его союзники. Используется для Бонни, когда он использует "Чужим Разумом".

:::warning Внимание
Ничего не делает на клиенте.
:::

# Аргументы

> `1` @boolean@ **onlyAudibleByTeammates**

- Должны ли слышать игрока только его союзники или нет.

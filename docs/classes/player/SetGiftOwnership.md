> <span class="fh-badge shared">shared</span> @Player@:SetGiftOwnership(@boolean@ ownsGift)

# Описание

Устанавливает статус того, имеет ли игрок несобранный подарок.

::: warning Уже используется режимом
Эта функция применяется режимом по умолчанию - чтобы игра не выдла второй подарок игроку, пока не подобран первый. Не используйте, если не знаете что делаете.
:::

# Аргументы

> `1` @boolean@ **ownsGift**

- Введите true, если игрок получил подарок, а если нет - false.

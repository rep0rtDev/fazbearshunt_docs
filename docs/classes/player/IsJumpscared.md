> <span class="fh-badge shared">shared</span> @boolean@ @Player@:IsJumpscared()

# Описание

Скримерят ли игрока? Используйте, чтобы не дать аниматронику случайно заскримерить игрока, которого уже скримерит кто-то другой.

# Возвращает

> `1` @boolean@

- Если игрока скримерят, возвращает true, и false если нет.

> <span class="fh-badge server">server</span> **stats.SetMin(@string@ name, @number@ minValue)**

# Описание

Задаёт минимальное значение интереса. Если игрок не набрал статистику до этого уровня, её не покажет.

# Аргументы

> `1` @string@ **name**

- Название статистики.

> `2` @number@ **minValue**

- Минимальное значение интереса..

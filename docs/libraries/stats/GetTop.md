> <span class="fh-badge server">server</span> @Player@, @number@ **stats.GetTop(@string@ statName)**

# Описание

Добавляет значение к статистике игрока.

# Аргументы

> `1` @string@ **statName**

- Название статистики.

# Возвращает

> `1` @Player@ **ply**

- Игрок с самым лучшим значением статистики.

> `2` @number@ **value**

- Значение статистики.

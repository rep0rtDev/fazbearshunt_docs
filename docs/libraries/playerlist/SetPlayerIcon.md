> <span class="fh-badge client">client</span> **playerlist.SetPlayerIcon(@string@ steamID64, @string@ icon)**

# Описание

Устанавливает иконку игроку в списке игроков.

Перед этим ознакомьтесь с тем, как добавлять сеты иконок - [playerlist.AddIconSet()](/libraries/playerlist/AddIconSet)

# Аргументы

> `1` @string@ **steamID64**

- [Player:SteamID64](https://wiki.facepunch.com/gmod/Player:SteamID64) которому устанавливаем иконку.

> `2` @string@ **icon**

- Название иконки.

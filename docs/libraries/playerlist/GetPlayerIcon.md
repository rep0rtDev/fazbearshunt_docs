> <span class="fh-badge client">client</span> @string@ **playerlist.GetPlayerIcon(@string@ steamID64)**

# Описание

Даёт узнать текущую иконку игрока в списке игроков через его [Player:SteamID64](https://wiki.facepunch.com/gmod/Player:SteamID64)

Для установки иконки - [playerlist.SetPlayerIcon()](/libraries/playerlist/SetPlayerIcon)

# Аргументы

> `1` @string@ **steamID64**

- [Player:SteamID64](https://wiki.facepunch.com/gmod/Player:SteamID64) которому устанавливаем иконку.

# Возвращает

> `1` @string@

- Название иконки.

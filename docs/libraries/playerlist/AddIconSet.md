> <span class="fh-badge client">client</span> **playerlist.AddIconSet(@string@ icon, @string@ material, @number@ size = 16, @Color@ color = Color(255,255,255))**

# Описание

Добавляет сет иконок, которые позже могут быть назначены определённым игрокам.

# Аргументы

> `1` @string@ **icon**

- Название иконки.

> `2` @string@ **material**

- Путь до текстуры иконки.

> `3` @string@ **size** = 16

- Размер иконки.

> `4` @string@ **color** = Color(255,255,255)

- Цвет никнейма игрока.

> <span class="fh-badge server">server</span> **highlight.NotifyTarget(@Player@ target, @Entity@ pill, @bool@ isAffected)**

# Описание

Оповещает `target` звуком просвета.

::: warning Учтите
Если на сервере включена настройка "Невнятный Просвет", то несмотря на установленный `isAffected`, игра воспримит её как `false`.
:::

# Аргументы

> `1` @Player@ **target**

- Имя Пилла, например `pill_wchica2`.

> `2` @Entity@ **pill**

- Пилл-Энтити просвечивающего игрока. Нужно, чтобы игра смогла использовать уникальный звук просвета. Необязательно указывать.

> `3` @bool@ **isAffected**

- Включить звук успешного просвета, или нет.

> <span class="fh-badge server">server</span> **highlight.ByDistance(@Player@ ply, @Entity@ pill)**

# Описание

Просвечивает игроку `ply` всех выживших. Все аниматроники режима со способностью "просвет" используют именно эту функцию.

# Аргументы

> `1` @Player@ **ply**

- Игрок, который вызывает просвет.

> `2` @Entity@ **pill**

- Пилл-Энтити игрока.

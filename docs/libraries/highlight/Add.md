> <span class="fh-badge server">server</span> **highlight.Add(@Player@ ply, @table@<@Player@> victims, @number@ duration, @Color@ color = Color(255,0,0))**

# Описание

Просвечивает игроку `ply` всех игроков `victims`, с возможностью установки цвета и продолжительности.

# Аргументы

> `1` @Player@ **ply**

- Игрок, который вызывает просвет.

> `2` @table@<@Player@> **victims**

- Игроки, которые будут просвечены.

> `3` @number@ **duration**

- Продолжительность просвета.

> `4` @Color@ **color** = Color(255,0,0)

- Цвет просвета.

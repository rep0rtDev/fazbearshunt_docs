> <span class="fh-badge server">server</span> **highlight.GetCooldown(@Player@ ply)**

# Описание

Позволяет узнать кулдаун просвета.

Кулдаун можно установить через [highlight.Cooldown](/libraries/highlight/Cooldown)

# Аргументы

> `1` @Player@ **ply**

- Игрок, у которого проверяем кулдаун.

# Возвращает

> `1` @number@

- Возвращает время до конца кулдауна. Если кулдаун закончился, то возвращает `0`.

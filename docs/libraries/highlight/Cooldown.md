> <span class="fh-badge server">server</span> **highlight.Cooldown(@Player@ ply, @number@ duration)**

# Описание

Устанавливает кулдаун на просвет. Кулдаун автоматически учитывается только в [highlight.ByDistance](/libraries/highlight/ByDistance)

# Аргументы

> `1` @Player@ **ply**

- Игрок, которому устанавливается кулдаун.

> `2` @number@ **duration**

- Продолжительность кулдауна просвета.

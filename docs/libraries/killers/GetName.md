> <span class="fh-badge shared">shared</span> @string@ **killers.GetName(@string@ pill)**

# Описание

Возвращает техническое имя Пилла.

# Аргументы

> `1` @string@ **pill**

- Название Пилла, например `pill_wfreddy2`.

# Возвращает

> `1` @string@

- Техническое имя Пилла.

## Пример

```lua
print( killers.GetName( "pill_wfreddy2" ) )
```

**Вывод**:

```lua
freddy
```

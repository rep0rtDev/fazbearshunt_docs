> <span class="fh-badge shared">shared</span> @bool@ **killers.Register(@string@ pill, @string@ name, @string@ fullname, @Color@ color, @string@ category)**

# Описание

Позволяет получить портрет Пилла, которая используется в интерфейсе аниматроников, слева снизу.

# Аргументы

> `1` @string@ **pill**

- Название Пилла, например `pill_wfreddy2`.

> `2` @string@ **name**

- Техническое имя Пилла, например `freddy`.

> `3` @string@ **name**

- Полное имя Пилла. Можно вставить переводимую строку.

> `4` @Color@ **color**

- Цвет интерфейса аниматроников.

> `5` @string@ **category**

- Категория Пилла. Прямо сейчас используется только в Админ-Панели.

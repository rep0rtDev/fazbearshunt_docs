> <span class="fh-badge shared">shared</span> @table@ **killers.GetAllPreferables(@boolean@ secondaries = false)**

# Описание

Возвращает таблицу всех играбельных Пиллов. (Те, которые могут появляться в выборке аниматроников)

Установив `secondaries` на `true`, включает в список вторичных аниматроников, таких как Шедоу Фредди или Той Чика.

# Возвращает

> `1` @table@

- Таблица играбельных пиллов.

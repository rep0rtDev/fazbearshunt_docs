> <span class="fh-badge shared">shared</span> @bool@ **killers.GetPortrait(@string@ pill)**

# Описание

Позволяет получить портрет Пилла, которая используется в интерфейсе аниматроников, слева снизу.

# Аргументы

> `1` @string@ **pill**

- Имя пилла, например `pill_wfreddy2`.

# Возвращает

> `1` @IMaterial@ или @nil@

- Портрет данного Пилла, либо `nil` если не найден.

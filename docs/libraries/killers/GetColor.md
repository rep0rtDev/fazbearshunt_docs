> <span class="fh-badge shared">shared</span> @Color@ **killers.GetColor(@string@ pill)**

# Описание

Позволяет получить цвет Пилла.

# Аргументы

> `1` @string@ **pill**

- Имя пилла, например `pill_wfreddy2`.

# Возвращает

> `1` @Color@ = Color(255,255,255)

- Цвет Пилла. Если не найдено, выдаёт белый цвет.
